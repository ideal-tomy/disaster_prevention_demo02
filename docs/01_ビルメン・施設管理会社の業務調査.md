# ビルメンテナンス会社・施設管理会社の業務調査

作成日: 2026年9月9日
用途: 施設管理システムのデモ制作用の下地資料

---

## 1. 誰が誰に何を頼んでいるか

この業界は、建物を持っている側と、実際に手を動かす側が分かれている。デモを作るときは「画面を見せる相手が、この並びのどこにいるのか」を先に決める必要がある。

| 立場 | 呼び方 | やること |
| --- | --- | --- |
| 建物を持つ | オーナー、自治体、事業会社 | 予算を決める。修繕するかどうかを決める |
| 建物を運営する | 管理会社、PM会社 | テナント対応、収支、業者の選定と発注 |
| 建物を維持する | ビルメンテナンス会社（元請） | 清掃・設備・警備をまとめて請け負う |
| 専門作業をする | 協力会社、メーカー | 消防設備点検、昇降機保守、外壁調査、貯水槽清掃など |

言葉の使い分けは次のとおり。

- **BM（ビルマネジメント）** … 建物と設備が正常に動いている状態を保つ。「動くかどうか」を見る
- **PM（プロパティマネジメント）** … 賃料や稼働率など、建物の収益を見る
- **AM（アセットマネジメント）** … 資産としていくらかかり、いくら戻るかを見る
- **FM（ファシリティマネジメント）** … 施設をどう使うかまで含めて考える。経営側の言葉

中小のビルメン会社が日常的に扱っているのはBMの範囲。FMという言葉が出てくるのは、自治体の公共施設や、複数拠点を持つ大企業の総務部門が相手のとき。

## 2. 業務は5つに分かれる

全国ビルメンテナンス協会の整理では、次の5つが柱になっている。

### 2-1. 清掃管理

床だけでなく壁・扉・什器まで含めて美観と衛生を保つ。建物の用途で内容が変わる。最近は汚れてから落とすのではなく、汚れを持ち込ませない方向に変わってきている。

作業は3種類に分かれ、契約もこの単位で結ばれる。

| 区分 | 頻度の例 | 作業の中身 |
| --- | --- | --- |
| 日常清掃 | 週2〜5回、1回2〜3時間 | 掃除機がけ、トイレ、給湯室、ゴミ回収、拭き上げ |
| 定期清掃 | 月1回、隔月、年4回など | 床の機械洗浄とワックス、カーペット洗浄、ガラス清掃 |
| 特別清掃 | 単発、年1回 | エアコン分解洗浄、高所ガラス、外壁高圧洗浄、貯水槽清掃 |

マンションの目安では、床の機械洗浄とワックスが年4回程度、ガラス清掃が年2回、照明や高所のほこり取りが年1回、外壁の高圧洗浄と貯水槽清掃が年1回以上。

見積もりの作り方も2つに分かれる。日常清掃は「人数×時間単価×回数」で、ほぼ人件費。定期清掃は「作業別の単価×数量」で、機械と薬剤の代金が乗る。見積書に「定期清掃 一式」と書かれていると、発注側から内訳を求められる。

### 2-2. 衛生管理

建築物衛生法で決まっている環境基準を満たしているかを測って調整する。

- 空気環境（浮遊粉じん、温度、相対湿度、一酸化炭素、二酸化炭素、気流）を2か月以内に1回測る
- 飲料水の残留塩素測定と水質検査、貯水槽清掃、給水管洗浄
- 排水槽・汚水槽の清掃、排水設備の点検
- ねずみと害虫の駆除

対象は、店舗・事務所・興行場・百貨店・図書館などに使われる延べ面積3,000㎡以上の建物（学校は8,000㎡以上）。この建物を特定建築物と呼び、建築物環境衛生管理技術者（ビル管理士）を選任しなければならない。

### 2-3. 設備管理

電気・空調・給排水・防災・昇降機を動かし、監視し、点検し、記録する。現場では「5大設備」と呼ばれる。

| 設備 | 主な対象 |
| --- | --- |
| 電気 | 受変電設備、分電盤、照明、非常用発電機 |
| 空調 | 空調機、換気設備、フィルター、冷温水系統 |
| 給排水 | 給水ポンプ、貯水槽、排水設備、トイレ、水回り |
| 防災 | 火災報知設備、消火設備、避難誘導灯、非常放送 |
| 昇降機 | エレベーター、エスカレーター |

ここで大事なのは、設備管理員が全部を自分で直すわけではないこと。実際にやっているのは、異常を早く見つけて、影響の範囲を切り分け、専門業者に正しく伝えて、復旧までの段取りを組むこと。昇降機はメーカーや専門業者が点検し、設備管理員は停止時の一次確認と利用者対応、連絡、立会いを担うのが普通。

### 2-4. 警備・防災

警備員が常駐して立哨と巡回をする。防災センターで監視装置を見て、異常が出たら現場に出る。防火管理の側では、消防計画の作成と消防用設備の点検・維持がある。警備業は警備業法の認定業者しかできない。

### 2-5. 建物・設備保全

受変電、発電機、ボイラー、冷凍機の保守と、法定点検・性能検査の受検。点検データを積み重ねて、経年で何が劣化しているかを見る。

このほかに、駐車場管理、廃棄物処理、植栽、貸館の受付などが付いてくる場合がある。

## 3. 現場の1日

デモの第1部（問題の可視化）を作るなら、この時間の流れをそのまま使える。

### 日勤の現場

| 時間帯 | やること |
| --- | --- |
| 朝 | 夜間の警報とトラブルの有無を確認する。監視盤のログ、日誌、当直メモ、まだ直っていない案件を見る。その日の作業予定とテナントからの申告も見る |
| 午前 | 巡回点検。機械室、電気室、受水槽まわり、空調機、トイレ、共用部を回る。異音、異臭、振動、漏水、結露、温度の違いを見る。圧力計と温度計の数値も記録する |
| 日中 | 依頼対応。照明が点かない、空調が効かない、異音がする、水が流れにくい。ブレーカー、操作盤、設定値、フィルター、止水栓を確認して、その場で直せるかを判断する |
| 午後 | 専門業者の立会い、点検結果の記録、見積内容の確認、管理会社への報告 |
| 夕方 | 日中に対応した設備をもう一度見る。未対応の項目と翌日の予定を整理して引き継ぐ |

### 宿直の現場

8時から翌8時までの勤務。中央監視室で設備を監視し、フロアの温度と湿度を調整し、テナントからの申告を受ける。ボイラーや冷凍機などの熱源機器を発停する。

夜間に警報が出たら、まず安全を確保して、原因と影響の範囲を確認する。応急で直せるなら直し、無理なら保守会社・管理会社・テナントに状況を伝える。夜中に大がかりな修理をするより、被害を広げずに翌朝へ正確に引き継ぐほうを選ぶ場面が多い。

### トラブル時の初動

設備が変わっても手順は変わらない。

1. 安全確保（感電、漏水、火災、転倒を避ける）
2. 影響範囲の確認（1室だけか、フロア全体か、建物全体か）
3. 応急対応（止水、復電、リセット、使用停止のどれを選ぶか）
4. 連絡・手配（保守会社、管理会社、テナントへ必要な情報を渡す）
5. 記録（発生時刻、場所、症状、対応、結果を残す）

空調が効かないという1件でも、設定ミス、フィルターの詰まり、機器の故障、電源系統、外気の条件と、原因の候補が複数ある。最初に原因を決めつけないことが現場のルールになっている。

## 4. 年間で必ず回るもの（法定点検）

ここが施設管理システムの中心。根拠になる法律ごとに、点検の対象・頻度・報告先・資格がばらばらに決まっている。

| 根拠法 | 点検対象 | 点検頻度 | 報告頻度 | 報告先 |
| --- | --- | --- | --- | --- |
| 建築基準法12条 | 特定建築物（敷地・構造） | 3年以内ごと | 同じ | 特定行政庁 |
| 建築基準法12条 | 建築設備・防火設備・昇降機 | 1年以内ごと | 同じ | 特定行政庁 |
| 消防法17条の3の3 | 消防用設備等（機器点検） | 6か月以内ごと | — | — |
| 消防法17条の3の3 | 消防用設備等（総合点検） | 1年以内ごと | 特定防火対象物は1年ごと／非特定は3年ごと | 消防長または消防署長 |
| 建築物衛生法 | 特定建築物の空気環境 | 2か月以内ごと | 年1回 | 都道府県知事など |
| 電気事業法 | 自家用電気工作物 | 月次・年次（設備区分による） | 必要に応じて | 経済産業省（産業保安監督部） |

このほか、冷凍機は高圧ガス保安法、給水設備は水道法、合併浄化槽は浄化槽法が関わる。

### システムを作るうえで外せない3つの事実

**（1）点検の頻度と報告の頻度は別物**

消防用設備は、点検が6か月ごと（機器点検）と1年ごと（総合点検）の2種類あり、報告は特定防火対象物なら1年に1回、非特定なら3年に1回。点検カレンダーと報告カレンダーを別のレイヤーで持たないと破綻する。

**（2）12条点検は4つに分かれ、それぞれ資格者が違う**

特定建築物調査、建築設備検査、防火設備検査、昇降機検査。一級・二級建築士か、それぞれの検査員資格が要る。物件ごとに「どれが該当するか」を確定させ、資格者を割り当てるところが運用の出発点。初回は検査済証の交付から、敷地・構造は6年以内、昇降機・建築設備・防火設備は2年以内。

**（3）記録の保管期間も法律ごとに違う**

消防用設備等の点検結果報告書は3年、建築物衛生法の帳簿書類は5年。

### 主な点検の中身

- **特定建築物調査** … 外壁の劣化と落下危険箇所の打診、避難経路と防火区画の維持状況、屋根と外装材の固定状況。タイル張りやモルタル仕上げで10年を超える建物は外壁の打診調査が必須
- **建築設備検査** … 換気設備の風量測定、排煙設備の起動試験、非常用照明の点灯確認と蓄電池容量試験
- **防火設備検査** … 防火戸と防火シャッターの作動確認、連動制御設備の試験、煙感知器との連動確認
- **昇降機検査** … ロープとワイヤーの摩耗確認、制動装置の作動試験、戸開走行保護装置と地震時管制運転装置の動作確認
- **消防用設備** … 現場で見つかる不備は、消火器の期限切れ・破損・位置変更、スプリンクラーヘッドの障害物や塗装、避難経路の物品堆積と防火戸の閉鎖障害に集中している

## 5. 会社の裏側で回っている業務

現場作業だけを描いてもデモにならない。受注から入金までのつながりを押さえる。

```
引き合い → 現地調査 → 積算・見積 → 契約 → 年間計画の作成
→ 人員配置（シフト）→ 協力会社への発注 → 作業実施 → 報告書作成
→ 検収 → 請求 → 入金確認 → 契約更新
```

各段階でよく使われる書類と、そこで起きていること。

| 段階 | 書類 | 起きていること |
| --- | --- | --- |
| 積算・見積 | 見積書 | Wordのテンプレートを毎回編集する。1件20分程度 |
| 契約 | 業務委託契約書、仕様書 | 作業範囲と頻度、単価の内訳をここで固める |
| 年間計画 | 年間業務計画表 | 日常・定期・法定を1枚に並べる |
| 配置 | シフト表 | ホワイトボードや紙で組み、変更のたびに書き直す |
| 発注 | 発注書 | 協力会社に出す。取適法（旧下請法）の記載事項がある |
| 実施 | 点検表、作業日報 | 紙に手書きし、事務所に持ち帰る |
| 報告 | 点検報告書、月次報告書 | 転記して清書する。1件30分程度 |
| 請求 | 請求書 | Excelで集計して印刷・郵送。月2時間程度 |

### 特に手が止まる場所

- **報告書づくり** … 現場で紙に書き、事務所でExcelに転記する。写真は別に撮って後から紐づける。報告業務だけで月に20〜30時間という規模になる会社がある
- **過去の記録を探す** … 紙のファイルから半年前の点検結果を出すのに1件10〜15分かかる
- **Excelの限界** … 案件が30件を超えたあたりから、最新版がどれか分からなくなる。現場のスマホから見られない。入力ルールが揃わず集計できない
- **人の頭の中にしかない情報** … 建物ごとの清掃手順、設備の癖、オーナーとのやり取りの経緯。担当が辞めると引き継ぎがゼロからになる
- **シフト** … 複数の物件に複数のスタッフを当てはめる組み合わせの問題。急な欠員が出ると全部が崩れる
- **報告漏れ** … 法定点検の報告を落とすと、行政指導や契約の失注に直結する。担当者個人のカレンダーで管理していると、退職や休職で通知先が消える

## 7. 自治体・公共施設の場合

防災に絡めた施設管理システムを作るなら、ここが対象になる。

- 2012年の笹子トンネル事故を受け、総務省が全国の自治体に**公共施設等総合管理計画**の策定を要請した。その下に施設ごとの**個別施設計画**が置かれる
- 計画は作られたが、財源と人員が足りず実行できていない自治体が多い
- 建築基準法12条点検は、一定の用途と規模を満たす公共建築物にも義務がある。昇降機と遊戯施設は用途・規模に関係なく対象
- 国は地方公共団体向けに**BIMMS**という施設保全システムを用意している。全庁で情報を共有し、保全業務を標準化する狙い
- 民間側にも自治体向け製品がある（例: 公共施設計画保全管理システムPPS。施設単位のカルテ表示、修繕履歴、写真を含む文書のデータベース管理、修理修繕の優先度を点数で評価する機能など）

自治体案件で特徴的なのは、**説明責任**が機能要件に入ること。誰がどの基準でどう評価して、なぜその工事を先にやると決めたのかを、後から示せる形にしておく必要がある。民間のビルメンにはあまりない要求。

## 8. デモの題材として見たときの評価

| 題材 | 1〜2分で腹落ちするか | 備考 |
| --- | --- | --- |
| 点検と報告のカレンダーが2本ある | ◎ | 「点検は済んでいるのに報告を落とす」という構造を図にできる。専門知識なしで読める |
| 紙の点検表 → 転記 → 報告書 | ◎ | 二度手間が図形で描ける。既存の点検記録デモと重なるので描き方を変える必要がある |
| 過去の記録が探せない | ○ | 「半年前の結果を出すのに15分」は伝わるが、絵にすると地味 |
| 担当者が辞めると何も残らない | ◎ | 知見継承デモと題材が重なる。使い分けの整理が要る |
| シフトの組み替え | ○ | シフト管理デモが既にある |
| 建物ごとにどの法律が該当するか分からない | ◎ | 物件と法律の対応表という、この業界特有の構造。他業界では見ない |
| 異常の一次対応（切り分けと連絡） | ◎ | 「直すのではなく、広げない」という現場の判断がそのまま図になる |

**もっとも図にしやすい構造**は次の1文にまとまる。

> 1つの建物に、頻度も報告先も違う点検が何本も並行して走っていて、点検を済ませたことと報告を出したことが別々に管理されている。だから、点検はやったのに報告だけが落ちる。

これは箱を並べる図ではなく、**同じ建物から出た線が別々の期限に向かって伸びていて、線ごとに終点が違う**という物理関係に変換できる。ラベルを全部消しても、線の長さと終点の違いだけで意味が残る。

もう1つ、防災に建て付ける場合は次の構造が使える。

> 点検で「異常なし」と書かれた設備が、災害のときに使えるかどうかは別の話。使えるかどうかを決めるのは、点検の結果ではなく、そこに至るまでの変化の積み重ね。
