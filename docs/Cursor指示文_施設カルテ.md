## 実装フェーズで貼る本文

翠嶺市総合体育館コンソールに、施設カルテを追加してください。添付の `施設カルテ_要件.md` が仕様です。先に全部読んでから着手してください。実装PLANがあるときは、PLANの順に従います。

### 前提

- 既存の Next.js アプリに追加します。新しいアプリは作りません
- 左メニューの項目は増やしません
- **場所・設備一覧と点検・対応状況⇄利用可否は残します。** カルテに差し替えません。行を開いた先（いまのドロワー）を時系列に厚くします。文言は 07 です
- 実際のデータベースや AI は繋ぎません。データはファイルに直接書きます
- 固有名詞・日付・件数は `docs/04_ペルソナと仮ナレッジ.md` が正です。04に無い値を作って画面に出さないでください

### やること

**1. 既存の「設備・場所」を残したまま、開いた先を読む**

トグル、18行、先頭アリーナ、Z02〜Z05はインシデント、それ以外はドロワー、は維持します。捨てるのはドロワーの薄いkvだけです。判断に迷う箇所は実装前に質問してください。

**2. データの形を作る**

要件の「データの形」のとおり、施設・設備・出来事の3つに分けます。

出来事は、点検・不具合・修繕・画像確認・期限の5種類を**同じ配列に入れてください**。種類ごとに配列を分けないでください。インシデントは種類を増やさず、参照先にします。

設備IDは `K-G3` のように、いま画面に出ている記号を使います。新しい記号を作らないでください。

**3. カルテの中身を作る**

- 建物の項目は、04に書いてあるものだけ出す。5/8 はシステム連携と同じ数字で、押すとシステム連携へ
- 設備の行はカルテの中身。場所18行の代わりにしない
- 時系列は設備を1つ開いた先。古い順、1本の縦線

**4. 時系列の見え方（ここが主役です）**

各行は「日付／種類／中身」の3つだけ。アイコンを増やさないでください。

次の2つを必ず入れてください。

- **期限の行**：次回点検日が来たら、線の上に自動で立ちます。人が入力した行ではありません
- **点線の区間**：実施の記録がないまま期限を過ぎた場合、その期限の行から次の行までの縦線を、薄い点線に変えてください

**5. 3つの設備で見え方を変える**

- 発電機（K-G3）：途中で点線に変わる線。日付は04のまま
- 受水槽（K-W1）：止まっていない線。04に無い点検を足さない。足すなら先に04へ
- 外壁（K-E3）：空にしない。2026/06/12 の剥離と、紙のままであることの1行

正常な設備を消さないでください。

**6. 他の画面から入れるようにする**

要件の入口表どおり、統合ダッシュボード・インシデント・書類・画像確認から時系列に飛べるようにします。戻れるようにしてください。Z02〜Z05 の行クリックはインシデントのままです。

### 変えないこと

- 左メニューの項目
- 設備・場所の保全⇄開館と18行の並び
- 上部の帯（時刻と日付、施設名）
- 色のトークン、角丸、余白、文字の大きさ
- 他の画面のレイアウト
- 市版のコードを import すること

既存のコンポーネントとスタイルを再利用してください。

### 数値と記号

次の値は既存の画面に出ているものです。**1つもずらさないでください。**

- カメラ番号：CAM-総合-E01、CAM-総合-N02、CAM-総合-W03

### 言葉

- 状態は既存の語だけ使う（期限切れ、記録済み、記録なし、対応が必要、問題なし、確認できていない、紙のまま、確認中）
- 「劣化度」「保全計画」「ライフサイクル」「公共施設等総合管理計画」「優先順位」「点数」「ブロックチェーン」を画面に出さないでください
- 1文に主語と述語を1組。「業者の紙を高木がファイルした」
- DEMO、モック、所要約2分、説明の見出しを足さないでください

### 実装ルール

- 基準は投影 1280px。370px にはしない
- 既存シェルのライトのまま。ダークモード用の別テーマを足さない
- アニメーションを入れる場合は `transform` と `opacity` だけ
- 分析や予測を足さない。並べているだけにする
- 優先順位や点数を出さない。それは全庁版

### 終わったら確認すること

- 保全⇄開館の一覧が残っているか
- 時系列から文字を全部消しても、線の長さと点線の区間で「何も起きていない期間がある」と読めるか
- 受水槽が残っていて、外壁が空になっていないか
- 4か所からカルテに入って、戻ってこられるか
- 日付・記号・数値が他の画面と一致しているか
- 左メニューの項目が増えていないか

### 進め方

一度に全部書かず、次の順で進めて、それぞれ確認させてください。

1. 既存の「設備・場所」を残す範囲と、ドロワーを厚くする範囲
2. データの形（施設・設備・出来事）。04に無い値は入れない
3. カルテの建物見出しと設備の行
4. 時系列（点線を含む）
5. 他の画面からの導線
