文言監査レポートに基づく修正仕様。既存01・03・04の文言指定と矛盾する場合、本書を優先する。監査レポート06は修正前の記録として保持する。

## 適用範囲

現在のLP・グループ付き一覧・相関図などの構成を維持し、表示文言を更新した。以前のレポートに記載されていても、現在削除されている説明文・印刷ボタン等は復活させていない。

- 製品名：総合体育館 施設管理
- 画面名：施設の状況／場所・設備一覧／要対応事項／画像確認／点検・開館前の記録／データ連携状況／AIアシスタント
- 利用判定：利用可能／条件の確認が必要／利用不可／利用可否が未確認。判定コード・件数は変更しない。条件未確認のまま利用を承認する意味ではない。
- 点検・対応状況：期限超過／今月が期限／記録あり／記録なし。点検と対応の期限は区別が未定義のため、未確定のものを「点検期限」と断定しない。
- 資料の連携状態：取り込み済み／内容を確認中／未連携。設備の利用判定とは別。
- 「—」は情報未登録。対象外・正常・未確認を推測して補完しない。
- K-IDは内容を併記する。説明用の短い名称であり、新しい公式基準名を定義したものではない。

## 意味が曖昧だった箇所の扱い

1. サブアリーナは電源設備と表現しない。夜間利用には別途電源の確認が必要と記載。代替供給元や使用許可を創作しない。
2. 体育館全体の確認事項は、車両・非常口の備品・発電機の点検期限・消火器の位置の4項目で統一。個別の利用判定は開館承認ではない。
3. 期限の種類が不明な項目は「記録上の期限」と表記。Z04・Z08・Z18の具体的期限や、外壁周辺の立入範囲は新たに設定しない。
4. 白いバンの画像を判定して更新するのは「搬入口画像の確認者」。開館前確認票全体の承認者とは扱わない。
5. 外壁の資料は未連携だが手入力記録は存在する。外壁そのものを未確認・正常と書き換えない。
6. 発電機の写真は点検票を判読できない旨を明記。実資料の追加や判定手順の設計は本修正の対象外。
7. 車両については「通行を妨げる」に統一。通行不能・全面封鎖とは断定しない。
8. 記録上の判定と現地の状態を区別。棚卸済みを安全点検済みに読み替えない。
9. 2026/03/18は発電機資料の保管日と明示。資料作成日や点検実施日に読み替えない。

## 要対応事項

搬入口の車両と、発電機の点検期限超過への対応が必要です

東側搬入口では車両が通行を妨げ、西側非常口の前には備品があります。発電機は点検期限（2026/08/28）を過ぎており、夜間の電源を確認できていません。アリーナ単体は記録上、利用可能と判定されています。体育館全体の開館前には、車両・備品の移動と消火器の設置位置を確認してください。日中・夜間とも、開館の可否は担当者が判断します。サブアリーナの夜間利用には、別途電源の確認が必要です。

1. 予約台帳の利用予定と、北側入口前の人数を確認する（予約台帳は未連携）
2. 搬入予定を確認し、東側搬入口の車両を移動できるか確認する
3. 非常口前の備品を、通行を妨げない場所に移動する（2026/09/09の指摘への対応は未完了）
4. 発電機の点検報告書を確認する。サブアリーナ（Z16）を夜間に利用できるか、電源を含めて確認する

## AIの質問と回答

AI APIは使わない。各質問と固定回答を一組で更新し、未知の質問を「該当記録なし」と断定しない。回答ごとに関連する記録のリンクを設定し、未対応入力には無関係なリンクを出さない。利用可能の一覧は返さない。

### 開館前に、いま確認・対応することは何ですか

開館前に、次の4項目を確認してください。

1. 予約台帳の利用予定と、北側入口前の人数を確認する（予約台帳は未連携）
2. 搬入予定を確認し、東側搬入口の車両を移動できるか確認する
3. 非常口前の備品を、通行を妨げない場所に移動する（2026/09/09の指摘への対応は未完了）
4. 発電機の点検報告書を確認する。サブアリーナ（Z16）を夜間に利用できるか、電源を含めて確認する

アリーナ単体は記録上、利用可能です。体育館全体は条件の確認が必要です。開館の可否は担当者が判断します。

関連する記録：要対応事項。

### 発電機の記録は、どこまで進んでいますか

非常用発電機（K-G3）の記録は、次までです。

・2026/03/18は点検報告書の保管日です。点検の実施日ではありません。保管したのは高木（総務）です。
・2026/08/28は記録上の期限です。実施の記録はありません。
・2026/09/12の機械室の写真は、点検票が貼られたままです。票の文字は判読できません。
・期限以降の実施・部品交換の記録はありません。

夜間の電源は未確認です。開館の可否は担当者が判断します。

関連する記録：場所・設備一覧の K-G3（Z05）。

### 屋上と空調設備が未確認なのはなぜですか

屋上と空調設備は、利用可否を判断するための点検記録が登録されていません。

台帳への登録だけでは、利用できるか判断できません。点検記録を確認できるまで、利用可否が未確認の項目として表示します。

関連する記録：場所・設備一覧の利用可否（Z12）。

未対応入力：この質問には対応していません。下の3つの質問から選んでください。
